Auto Refresh & Clicker

설정 안내와 문제 해결

페이지 전체를 새로고침할지, 새로고침 후 클릭할지, 목록 자체의 새로고침 버튼만 누를지 먼저 정하세요. 사용하려는 웹페이지에서 확장 프로그램을 열고 아래 단계를 따라 설정하면 됩니다.

Safari 버전에서 아이콘 버튼 선택과 페이지 새로고침 없는 반복 클릭을 사용할 수 있습니다. Chrome 버전은 별도로 업데이트되므로 지원 기능은 해당 스토어에서 확인해 주세요.

이 페이지의 내용

먼저 확장 프로그램 켜기자동 새로고침새로고침 & 클릭클릭만 반복잘 작동하지 않을 때도움이 더 필요하신가요?

먼저 확장 프로그램 켜기

iPhone / iPad

iOS / iPadOS 15.4 이상이 필요합니다. 설정에서 앱 → Safari → 확장 프로그램을 여세요. 이전 시스템에서는 설정 → Safari → 확장 프로그램입니다. Auto Refresh & Clicker를 켜고 사용할 사이트 접근을 허용하세요.

Mac

macOS 12 이상 및 Safari 15.4 이상이 필요합니다. 설치된 앱에서 Safari 설정을 열고 확장 프로그램에서 Auto Refresh & Clicker를 활성화하세요. 웹페이지를 열고 Safari 도구 막대의 확장 프로그램 아이콘을 선택하세요.

Chrome · 컴퓨터

Chrome 웹 스토어에서 설치하세요. Chrome 확장 프로그램 메뉴에서 필요하면 아이콘을 고정한 뒤 대상 페이지에서 확장 프로그램을 여세요.

자동 새로고침

페이지 전체를 다시 불러와야 하는 대시보드나 상태 페이지에 사용하세요. 10초마다 새로고침하는 예시입니다.

  1. 대상 웹페이지에서 확장 프로그램을 열고 ‘자동 새로고침’을 선택하세요.
  2. 10초 프리셋을 선택하거나 다른 간격을 입력하세요. 초 단위의 1 이상 정수를 사용하세요.
  3. 시작한 뒤 실행 중 상태와 줄어드는 카운트다운을 확인하세요. 간격이 지나면 페이지를 다시 불러옵니다.
  4. 같은 탭에서 확장 프로그램을 다시 열면 작업을 확인하거나 중지할 수 있습니다. 확장 프로그램 창을 닫아도 작업은 중지되지 않습니다.

전체 페이지를 다시 불러오면 필터나 저장하지 않은 설정이 초기화될 수 있습니다. 페이지에 자체 새로고침 버튼이 있다면 ‘클릭만 반복’을 사용해 보세요.

새로고침 & 클릭

페이지를 새로고침한 다음 버튼을 누르거나 여러 링크를 순서대로 클릭해야 할 때 사용하세요.

  1. ‘새로고침 & 클릭’을 선택하세요. 첫 단계에서 웹페이지의 버튼이나 링크를 직접 선택하거나 제목을 입력하세요. 두 방법 모두 같은 대상을 지정하는 방법입니다.
  2. 웹페이지에서 대상을 선택했다면 확장 프로그램을 다시 여세요. 선택만으로 버튼이 실행되지는 않습니다. 클릭 후 대기 시간을 예를 들어 3초로 설정하세요.
  3. 필요하면 단계를 추가하세요. 번호 순서대로 클릭하고 각 클릭 후에 대기합니다. 마지막 단계의 대기가 끝나면 다음 새로고침으로 넘어갑니다.
  4. 시작하면 먼저 페이지를 다시 불러온 뒤 클릭 단계를 실행합니다. 결과를 확인하세요. 확장 프로그램을 다시 열어 중지하거나, 단계를 수정한 뒤 변경 사항을 적용할 수 있습니다.

새로고침 후 대상을 확실히 식별할 수 없다는 메시지가 나오면 버튼의 텍스트를 입력하거나 이름이 고유한 버튼을 선택하세요. 이 모드는 전체 페이지를 다시 불러옵니다.

클릭만 반복

전체 페이지를 새로고침하면 필터가 초기화되지만 목록에 자체 새로고침 아이콘이 있는 경우에 적합합니다.

  1. 웹페이지에서 필터를 설정한 다음 확장 프로그램을 열고 ‘클릭만 반복’을 선택하세요.
  2. 클릭 간격을 예를 들어 5초로 입력하세요. 버튼 또는 링크 선택 기능으로 목록의 새로고침 아이콘을 선택하세요. 글자가 없는 아이콘도 선택할 수 있습니다.
  3. 선택 후 페이지 안내에 따라 확장 프로그램을 다시 여세요. 선택한 대상을 확인하고 시작하세요.
  4. 목록이 업데이트되고 필터가 예상대로 동작하는지 확인하세요. 확장 프로그램을 다시 열면 다음 클릭 카운트다운과 클릭 횟수를 확인하거나 작업을 중지할 수 있습니다.

이 모드 자체는 페이지 새로고침을 요청하지 않습니다. 다만 버튼은 웹사이트의 원래 동작을 실행하므로 페이지가 바뀔 수 있습니다. 다른 페이지로 이동하거나 대상이 바뀌면 다시 선택한 후 시작하세요.

잘 작동하지 않을 때

Mac Safari에 확장 프로그램이 보이지 않아요

설치한 Mac 앱을 한 번 이상 연 뒤 Safari 설정 → 확장 프로그램을 확인하세요. macOS 12 이상과 Safari 15.4 이상이 필요합니다. Safari를 다시 열어도 보이지 않으면 버전과 설치 경로를 적어 지원팀에 문의하세요.

작업이 시작되지 않아요

일반 http 또는 https 웹페이지를 열고 Safari 설정에서 해당 웹사이트 접근을 허용하세요. 브라우저 설정, 새 탭과 일부 보호된 페이지에서는 작업을 실행할 수 없습니다. 다시 시도하기 전에 확장 프로그램의 오류 메시지를 확인하세요.

버튼을 사용할 수 없거나 여러 버튼이 일치해요

버튼이 보이고 활성화되어 있는지 확인한 후 확장 프로그램에서 정확한 버튼을 다시 선택하세요. 페이지가 바뀌면 저장한 대상이 더 이상 맞지 않을 수 있습니다. 같은 제목의 버튼이 여러 개일 때도 직접 선택해 주세요.

간격이나 설정이 올바르지 않다고 나와요

1 이상 정수의 초 단위를 사용하고 모든 클릭 단계를 입력하세요. 실행 중 설정을 수정했다면 변경 사항을 적용하고 작업 요약에서 실제 설정을 확인하세요.

iPhone이나 iPad에서 작업이 멈춰요

Safari를 화면에 띄워 두고 기기의 잠금을 해제해 두세요. iOS와 iPadOS는 백그라운드나 잠금 상태에서 브라우저 작업을 일시 중지할 수 있어 지속적인 백그라운드 실행은 보장되지 않습니다.

도움이 더 필요하신가요?

기기, 운영체제 및 브라우저 버전, 앱 버전, 작업 모드와 오류 메시지 전체를 알려 주세요. 내부 또는 비공개 사이트라면 버튼과 실행 결과를 설명해 주시면 됩니다. 주소나 기밀 데이터를 공유할 필요는 없습니다.
