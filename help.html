Auto Refresh & Clicker

Setup and troubleshooting

Start with the task your page needs: reload the whole page, click after a reload, or click a list’s own refresh button. Follow the steps below on the webpage you want to use.

The Safari app now supports selecting icon buttons and repeating clicks without reloading. Chrome is updated separately; check its store listing for available features.

Enable the extension first

iPhone / iPad

Requires iOS / iPadOS 15.4 or later. In Settings, open Apps → Safari → Extensions. On older systems, use Settings → Safari → Extensions. Enable Auto Refresh & Clicker and allow access to the sites you use.

Mac

Requires macOS 12 or later and Safari 15.4 or later. Open the installed app, choose Open Safari Settings, and enable Auto Refresh & Clicker in Extensions. Then open a webpage and select its Safari toolbar icon.

Chrome · Desktop

Install from the Chrome Web Store. Open Chrome’s Extensions menu, pin the extension if needed, and open it on the webpage you want to use.

Auto Refresh

For a dashboard or status page that needs a full reload. Here is a simple 10-second setup.

  1. Open the webpage, open the extension and choose Auto Refresh.
  2. Choose the 10-second preset, or enter another interval in whole seconds greater than zero.
  3. Choose Start. Check that the status shows Running and the countdown decreases. The page will reload when the interval ends.
  4. Reopen the extension on the same tab to check the task or choose Stop. Closing the extension window does not stop the task.

A full reload can reset a page’s filters or unsaved settings. If the page has its own refresh button, try Repeat click only instead.

Refresh & Click

Use this when a page needs to reload before you click a button or follow a sequence of links.

  1. Choose Refresh & Click. For the first step, either select a button or link on the page, or enter its title. These are two ways to choose the same target.
  2. When selecting on the page, choose the target and then reopen the extension. Selection itself does not activate the button. Set the wait after this click, for example 3 seconds.
  3. Add more steps if needed. They run in numbered order; each wait happens after that step’s click, including the last step before the next reload.
  4. Choose Start. The page reloads first, then the click steps run. Check the result. Reopen the extension to Stop, or edit the steps and choose Apply changes.

If a selected target cannot be identified reliably after reloading, enter its text or choose a button with a unique name. This mode reloads the whole page.

Repeat click only

For a list with its own refresh icon, where reloading the whole page would reset your filters.

  1. Set the filters you want on the webpage, then open the extension and choose Repeat click only.
  2. Enter a click interval, for example 5 seconds. Choose Select button or link and select the list’s refresh icon, even if it has no visible text.
  3. After selecting, reopen the extension as the page notice suggests. Confirm the selected target and choose Start.
  4. Watch the list update and check that the filters behave as expected. Reopen the extension to see the next-click countdown and click count, or choose Stop.

This mode does not request a page reload. The button still performs the website’s own action, which may change the page. If you navigate away or the target changes, choose it again before restarting.

If something is not working

The extension is missing in Safari on Mac

Open the installed Mac app at least once, then check Safari Settings → Extensions. You need macOS 12 or later and Safari 15.4 or later. If it is still missing after relaunching Safari, contact support with your versions and installation source.

The task will not start

Open an ordinary http or https webpage and allow the extension to access that website in Safari settings. Browser settings, new-tab pages and some protected pages cannot run tasks. Read the message in the extension before trying again.

The selected button is unavailable or several buttons match

Make sure the button is visible and enabled. Open the extension and select the exact button again. If the page changed, its saved target may no longer apply. A title that matches several buttons is not specific enough.

The interval or configuration is rejected

Use positive whole seconds and complete every click step. After editing a running task, choose Apply changes. Then check the task summary to confirm the active configuration.

The task pauses on iPhone or iPad

Keep Safari in the foreground and the device unlocked. iOS and iPadOS may suspend browser tasks in the background or while locked. Continuous background operation is not guaranteed.

Still need a hand?

Include your device, system and browser versions, app version, task mode and the exact error message. For an internal or private website, describe the button and what happens; you do not need to share its address or confidential data.
